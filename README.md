# Customer Segmentation System using Unsupervised Machine Learning

A Machine Learning project that identifies customer groups based on Annual Income and Spending Score using K-Means Clustering.

## Live Application

[Open Customer Segmentation System](https://utk-shekhar-customer-segmentation-system-app-0pdn75.streamlit.app/)

## Technologies Used
- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- Joblib

## Machine Learning Techniques
- Feature Selection
- Feature Scaling
- K-Means Clustering
- Agglomerative Hierarchical Clustering
- Principal Component Analysis (PCA)

## Dataset
Mall Customer Segmentation Dataset (200 customer records).
